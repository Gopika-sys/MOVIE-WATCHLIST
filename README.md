## 🎯 Overview

**MovieVerse** is a full-stack movie browsing platform that allows users to explore trending movies, filter movies by genre, and view detailed movie information in real time.

The application is built using **React** for the frontend, **Node.js & Express** for the backend, and **MongoDB** for data storage, ensuring scalability and smooth user experience.

---

## 💡 The Problem

- Difficulty in discovering movies based on user interests  
- Static platforms without real-time updates  
- Poor filtering and navigation experience

## ✅ The Solution

🎬 Dynamic movie data

## ✨ Key Features

### 🎥 Trending & Popular Movies
- Displays trending and popular movies dynamically
- Real-time data fetched from backend API

### 🎭 Genre-Based Browsing
- Filter movies by Action, Comedy, Drama, Thriller, etc.
- Efficient MongoDB array-based queries

### 📄 Detailed Movie Pages
- Poster, title, description, rating, and release year
- Previous and Next movie navigation

### ⚙️ Backend API
- RESTful APIs
- Full CRUD operations (Create, Read, Update, Delete)

### 📱 Responsive Design
- Works seamlessly on desktop, tablet, and mobile devices

## ⚡ Quick Start

### Prerequisites
- Node.js (v16 or higher)  
- MongoDB (Local or Atlas)  
- npm

## 🧠 Backend Setup

1. Navigate to backend folder and install dependencies:

```bash

`````

###🧠 Backend Logic
API Endpoints
Method	Endpoint	Description
GET	/api/movies	Fetch all movies
GET	/api/movies/:id	Fetch movie by ID
POST	/api/movies	Add new movie
PUT	/api/movies/:id	Update movie
DELETE	/api/movies/:id	Delete movie
